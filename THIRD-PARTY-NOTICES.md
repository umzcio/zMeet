# Third-Party Notices

zMeet vendors the following third-party code, compiled into the app. All of it
lives in `Sources/CWebRTCAPM/`, generated by `scripts/vendor-webrtc-apm.sh` from
unmodified upstream files:

- `webrtc/`: webrtc-audio-processing 2.1, WebRTC's audio processing module
  (the AEC3 echo canceller) as packaged by freedesktop.org, together with the
  third-party code it bundles.
- `abseil/`: the parts of Abseil that it needs.

`Sources/CWebRTCAPM/include/` and `Sources/CWebRTCAPM/zmeet/` are zMeet's own
code (MIT, see [LICENSE](LICENSE)).

Each component's license text ships beside its code at the path given below.
The texts whose terms ask for reproduction with binary distributions are also
reproduced here.
